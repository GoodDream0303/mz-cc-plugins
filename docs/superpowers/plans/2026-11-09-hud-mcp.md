# MCP HUD implementation plan

> **For agentic workers:** Use superpowers:executing-plans and test-driven development, task by task.

**Goal:** Separate persistent MCP connections from transient MCP calls and improve tool labels.
**Architecture:** Extend sanitized reader metadata, render MCP areas separately,
then preserve connection visibility through existing pagination.
**Tech stack:** Existing TypeScript, Node20+, terminal renderer; no new dependencies.
**Spec:** `docs/superpowers/specs/2026-11-09-hud-mcp-design.md`.

## Global constraints

- Current standalone CLI has no accessible App Server control socket. User chose
  interface/calls first; unknown connections must not be labeled connected.
- No daemon, Codex, trust, config, clipboard or installed runtime changes.
- Preserve source proof, bounded reads/history, dynamic-height caps and languages.

## Review focus

- Canonical and legacy MCP event duplication must not invent or retain active calls.
- Tool timestamps/call completion must not be inferred from arbitrary output text.
- Safe metadata extraction must not retain command arguments or secrets.
- Official identity filtering must be exact, with no substring-based exclusion.
- Connection pinning must coexist with warnings and tiny viewports without lost content.
