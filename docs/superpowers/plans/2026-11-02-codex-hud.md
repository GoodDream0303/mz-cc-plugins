# Codex HUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Deliver a configurable standalone multiline Codex HUD in native Windows Terminal, matching the user's claude-hud preferences.

**Architecture:** TypeScript modules convert incrementally read Codex telemetry into an allowlisted snapshot. A standalone renderer and configuration menu run in a dedicated Terminal pane. A launch descriptor and SessionStart hook bind each pane to its exact session.

**Tech Stack:** Node.js 20+, TypeScript, Node test runner, a maintained TOML parser, Windows Terminal CLI.

**Spec:** `docs/superpowers/specs/2026-11-02-codex-hud-design.md` (approved by the user in this conversation).

## Global Constraints

- Native Windows Terminal; no changes to claude-scope, task-handoff, Claude settings, or Codex binaries.
- User configuration under `%LOCALAPPDATA%/mz-codex-hud/config.json`; separate owned runtime files.
- Default refresh about one second and default bottom-pane fraction 0.22.
- No network telemetry, billable model smoke tests, approval bypasses, or implicit session switching.
- New plugin under `codex-hud/`; distinct Codex marketplace metadata.
- Preserve upstream MIT attribution for adapted claude-hud concepts/code.

## Review Focus

- Same-directory concurrent launches: separate launch IDs bind separate session IDs (Task 4).
- Cached token subsets and weekly-only quotas: no double counting or false 5h labels (Task 2).
- Corrupt config and partially written logs: preserve the last valid state without overwriting user files (Tasks 1, 2).
- Windows paths/arguments containing Unicode, spaces, quotes and semicolons: never become shell code (Task 4).
- Narrow/short panes and unknown capabilities: visible overflow/unknown indicators instead of misleading data (Task 3).

- `codex-hud/src/types.ts`: allowlisted snapshot, session, tool, agent, todo and quota interfaces.
- `codex-hud/src/config.ts`, `config-menu.ts`: schema/defaults, validation, atomic persistence, import and interactive selection.
- `codex-hud/src/reader.ts`, `sessions.ts`: incremental JSONL reducer and exact session discovery.
- `codex-hud/src/environment.ts`: cached read-only Git and MCP configuration facts.
- `codex-hud/src/render.ts`, `terminal-text.ts`: semantic groups, colors, Unicode wrapping and viewport.
