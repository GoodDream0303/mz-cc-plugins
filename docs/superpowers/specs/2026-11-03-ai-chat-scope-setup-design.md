# AI Chat Scope 新环境初始化

## 目标与范围

为从正式市场安装插件的 Windows 用户提供 setup 入口。用户已要求补充新环境支持；沿用 Python 3.9+、tkinter 和标准库，不引入 pip 包。基础监视默认可用，完整 Codex 授权/同步问答实时服务按需手动配置。

## 方案

采用共享 PowerShell 引导脚本：查找可用的 python、py -3 或 python3，再调用 Python 初始化与启动器。相较只补 README，这能诊断真实环境；相较打包解释器/自动下载安装 Python，保留轻量分发与现有依赖边界。

初始化检查 Windows、Python 版本、tkinter/Tk 实际可用性、插件入口和运行目录写入权限；仅在配置缺失时创建默认配置，兼容旧窗口设置，保留现有配置。启动也执行同样检查。启动失败给出具体原因；子进程早期错误写入明确的日志路径。

Claude 数据根尊重 CLAUDE_CONFIG_DIR，Codex 继续尊重 CODEX_HOME，默认读取当前用户目录。首次尚无会话属于提示，不阻止启动。提供 Claude/Codex 共用 setup 技能与更新后的 scope-show 入口。Windows hook 复用解释器探测，缺少环境时安静失败，不影响 CLI 决策。

## 约束与验收

- 不写插件安装目录，不自动安装 Python、不修改 CLI 全局配置、不授予 hook 信任、不启动实时服务。
- 不覆盖旧配置或有效的新配置，不保存提示词、命令、回答或令牌内容。
- 验证无旧配置、中文及空格路径、只有 py、缺少 tkinter、目录不可写、自定义数据根、重复 setup 和损坏配置。
- 使用正式安装内容的隔离副本验证初始化和双宿主状态；市场网络超时单独报告，不以本地副本冒充远端安装成功。
- 本次开发不自动发布或重装正式插件。
